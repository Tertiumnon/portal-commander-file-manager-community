# Portal File Manager 0.1.0

*October 2026 · First preview*

Welcome to the first preview of Portal File Manager: a fast, keyboard-first, two-panel file manager for Windows. This release lays the foundation:

- [Two panels, one keyboard](#two-panels-one-keyboard): copy and move between folders side by side.
- [Find your way fast](#find-your-way-fast): address bar with suggestions, favorites, disks and network shares.
- [Make it yours](#make-it-yours): nine themes, two icon packs, three keyboard layouts.

## Two panels, one keyboard

Two folders sit side by side, and <kbd>Tab</kbd> switches between them. Copy with <kbd>F5</kbd>, move with <kbd>F6</kbd>, create folders with <kbd>F7</kbd>, rename with <kbd>F2</kbd> and delete to the Trash with <kbd>F8</kbd> or <kbd>Delete</kbd>. You can also drag files from one panel to the other, or mirror one panel's folder in the other with the arrows between them.

Copying shows real progress (files, bytes and the current file), including files that OneDrive is still downloading, and you are asked before anything is replaced.

## Find your way fast

- **Address bar** with folder suggestions as you type; network shares work too (`\\server\share`).
- **Back and forward history** for each panel.
- **Disks** with free space at a glance, and the **Trash** with its size, right in the top bar.
- **Favorites**: pin folders, give them a name and an icon, drag to reorder, and open the first ten with <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>0</kbd>.
- **Four views**: list, small, large and very large icons, with image previews.
- **Folder sizes** on demand (∑), cached so they come back instantly.
- **Context menu** with Open with…, Copy path, Archive and Extract with 7-Zip or WinRAR, and the full Windows shell menu.

## Make it yours

- **Nine themes**: Default, Catppuccin, Atom One Dark, Dracula, GitHub Dark, GitHub Light, Tokyo Night, Nord and Monokai.
- **Two icon packs**: VS Code Great Icons and Material Icons.
- **Keyboard layouts** for Portal, Far Manager and Total Commander users, with a shortcut bar at the bottom.
- **Scale** the interface from 50% to 150% and pick the font and font size.
- **Export and import** your settings.
