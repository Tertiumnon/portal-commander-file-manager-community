# Keyboard shortcuts

> [Documentation and version scope](User.Guide.md#version-scope).

Choose Portal Default, Windows Explorer, Total Commander, Far Manager or macOS under **Settings → Interface → Shortcuts**. The shortcut panel's help icon opens the full table for that layout. Use that table when a key differs from the default examples below.

## Folder context: default layout

| Action | Keys |
| --- | --- |
| Open selection | Enter |
| Edit text | F4 |
| Copy / Move to other panel | F5 / F6 |
| New folder | F7 |
| Delete to Trash | F8 or Delete |
| Rename | F2 or Shift+F6 |
| Clipboard copy / paste | Ctrl+C / Ctrl+V |
| Filter current folder | Ctrl+F |
| Focus address | Ctrl+L |
| Refresh | Ctrl+R |
| Parent folder | Backspace or Alt+Up |
| Back / Forward | Alt+Left / Alt+Right |
| Switch panel | Tab |
| Show hidden / system files | Ctrl+H / Ctrl+S |
| Open favorite 1–10 | Ctrl+1 through Ctrl+0 |
| Show/hide right panel | Ctrl+Shift+P |
| Context menu | Shift+F10 |

## Opened-file context

| Action | Keys |
| --- | --- |
| Close file | Ctrl+Q or Escape; confirm before discarding unsaved text |
| Find in text/PDF | Ctrl+F; Cmd+F with the macOS layout |
| Replace in text | Ctrl+H |
| Edit read-only text | F4 |
| Save text / image rotation | Ctrl+S; Cmd+S with the macOS layout |
| Previous / Next read-only file | Alt+Page Up/Down or Alt+mouse wheel up/down |
| PDF/image zoom | Ctrl+/− or Ctrl+mouse wheel; Command also supported with the macOS layout |

Bindings depend on context: Ctrl+H means hidden files in a folder and Replace in text. Ctrl+S means system files in a folder and Save in an editor. The shortcut panel changes with the active file.

Inside an opened search bar, Escape closes search before closing the file. Editable text does not switch files through read-only navigation shortcuts.
